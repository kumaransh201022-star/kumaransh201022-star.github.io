Introduction

Do you want to learn MySQL from absolute beginner level? Then this tutorial is for you!

In this tutorial, we'll cover important MySQL basic concepts step-by-step, so that beginners can understand them properly.

CREATE DATABASE - First Step

First, we need to create a database. Use the CREATE DATABASE command:

CREATE DATABASE Company;

Done! A new database named Company has been created.

Creating Multiple Databases

You can create multiple databases like this:

CREATE DATABASE Company; CREATE DATABASE SCHOOL;

Now we have two databases: Company and SCHOOL.

DROP DATABASE - Deleting a Database

If you don't need a database, delete it with the DROP DATABASE command:

DROP DATABASE SCHOOL;
⚠️ Important: The DROP DATABASE command permanently deletes the database and all its data. Be very careful with this command!

CREATE TABLE - Creating Tables

Now we need to create a table inside the database. A table is like an Excel sheet with rows and columns.

Each column has a name and a data type that defines what kind of data it holds.

Data Types

  • INT - Whole numbers (like 1, 50, 100, 5000)
  • VARCHAR(100) - Text/String up to 100 characters
  • DATE - Date values (like 2026-08-30)
  • DECIMAL - Decimal numbers (like 1245120.99)

Creating a Table:

CREATE TABLE Employee ( ID INT, NAME VARCHAR(100), SALARY INT );

We created an Employee table with 3 columns:

  • ID - An integer (employee ID)
  • NAME - Text (employee name)
  • SALARY - An integer (employee salary)

USE Command - Selecting a Database

If you have multiple databases, tell MySQL which one to use:

USE Company;

Now all commands will work on the Company database.

SELECT * FROM - Viewing Table Data

To view all data in a table, use the SELECT * FROM command. The * means "all columns":

SELECT * FROM Employee;

This will display all rows and columns in the Employee table.

INSERT INTO - Adding Data to a Table

Now let's add data to the table using INSERT INTO command:

INSERT INTO Employee (ID, NAME, SALARY) VALUES (1, 'Ansh', 50000), (2, 'Anxh', 1245120);

We added 2 employees to the table:

ID NAME SALARY
1 Ansh 50000
2 Anxh 1245120

Why Explicitly Write Column Names?

By explicitly writing column names, MySQL knows exactly which value goes into which column. This makes your queries more reliable and easier to maintain.

SELECT Specific Columns

If you don't need all columns, select only what you need:

SELECT NAME, SALARY FROM Employee;

This will display only NAME and SALARY columns:

NAME SALARY
Ansh 50000
Anxh 1245120

MySQL Commands Summary

Command Purpose
CREATE DATABASE Create a new database
DROP DATABASE Delete a database
CREATE TABLE Create a new table
USE Select a database
SELECT * FROM Display all table data
INSERT INTO Insert new data into table
SELECT column FROM Display specific columns
